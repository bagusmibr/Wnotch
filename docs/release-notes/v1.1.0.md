## Wnotch 1.1.0

**🇬🇧 English** · [🇮🇩 Bahasa Indonesia](#-bahasa-indonesia)

### What's new
- ⏯️ **Music controls above the lyrics**: previous, play/pause and next now sit right above the synced lyric in the notch, so you can control Spotify without opening it.
- Tapping a control only controls the music. It no longer also opens Spotify or expands the notch.
- Turn it on or off in **Settings → Now Playing → Music controls above lyrics** (on by default).

### Install / update
1. Quit Wnotch if it is running.
2. Download **Wnotch.dmg** below and drag **Wnotch** into **Applications** (replace the old one).
3. Run once in Terminal (Wnotch is not notarized yet):
   ```bash
   xattr -dr com.apple.quarantine /Applications/Wnotch.app
   ```
4. Open Wnotch.

Requires **macOS 14 Sonoma or later** (Apple silicon and Intel). **Windows: coming soon.**

### 🇮🇩 Bahasa Indonesia

#### Yang baru
- ⏯️ **Kontrol musik di atas lirik**: tombol sebelumnya, putar/jeda, dan berikutnya kini ada tepat di atas lirik di notch, jadi Spotify bisa dikontrol tanpa dibuka.
- Menekan tombol hanya mengontrol musik, tidak lagi ikut membuka Spotify atau membesarkan notch.
- Nyalakan atau matikan di **Settings → Now Playing → Kontrol musik di atas lirik** (aktif secara bawaan).

#### Cara pasang / update
1. Tutup Wnotch jika sedang berjalan.
2. Unduh **Wnotch.dmg** di bawah, lalu seret **Wnotch** ke **Applications** (timpa versi lama).
3. Jalankan sekali di Terminal (Wnotch belum dinotarisasi):
   ```bash
   xattr -dr com.apple.quarantine /Applications/Wnotch.app
   ```
4. Buka Wnotch.

Butuh **macOS 14 Sonoma atau lebih baru** (Apple silicon dan Intel). **Windows: segera hadir.**
